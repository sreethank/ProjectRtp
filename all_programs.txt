Question: Create a Git Branching Story Project – "A Tale in Branches" using Git branches, where each branch represents a chapter, and finally merge all chapters into a single book.html file.
Folder: StoryProject
Filename: book.html

Commands:
# Step 1: Create the project & initial book
mkdir StoryProject
cd StoryProject
git init
git branch -M main

# Create book.html with:
# <html>
# <body>
# <h1>A Tale in Branches</h1>
# </body>
# </html>

git add book.html
git commit -m "Created book"

# Step 2: Create Chapter 1 branch
git switch -c chapter1

# Add to book.html before </body>:
# <h2>Chapter 1</h2>
# <p>A boy started his journey.</p>

git add book.html
git commit -m "Added chapter 1"
git switch main
git merge chapter1

# Step 3: Create Chapter 2 branch
git switch -c chapter2

# Add to book.html before </body>:
# <h2>Chapter 2</h2>
# <p>He reached a beautiful village.</p>

git add book.html
git commit -m "Added chapter 2"
git switch main
git merge chapter2

Final book.html:
<html>
<body>
<h1>A Tale in Branches</h1>

<h2>Chapter 1</h2>
<p>A boy started his journey.</p>

<h2>Chapter 2</h2>
<p>He reached a beautiful village.</p>
</body>
</html>

Question: Implement a palindrome program in Java using Docker.
Folder: DockerPalindrome

File 1: Palindrome.java
import java.util.Scanner;

class Palindrome {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter number: ");
        int n = sc.nextInt();
        int temp = n, rev = 0;

        while (n > 0) {
            rev = rev * 10 + n % 10;
            n = n / 10;
        }

        if (temp == rev)
            System.out.println("Palindrome");
        else
            System.out.println("Not Palindrome");
    }
}

File 2: Dockerfile
FROM eclipse-temurin:21-jdk
WORKDIR /app
COPY Palindrome.java .
RUN javac Palindrome.java
CMD ["java", "Palindrome"]

Commands:
docker build -t palindromeapp .
docker run -it --rm palindromeapp

import org.openqa.selenium.*;
import org.openqa.selenium.edge.EdgeDriver;

public class RegistrationTest {
    public static void main(String[] args) {
        WebDriver driver = new EdgeDriver();

        driver.get("http://localhost:8084");

        driver.findElement(By.id("name")).sendKeys("Sreethan");
        driver.findElement(By.id("email")).sendKeys("test@gmail.com");
        driver.findElement(By.id("phone")).sendKeys("9876543210");
        driver.findElement(By.id("gender")).sendKeys("Male");
        driver.findElement(By.id("event")).sendKeys("Hackathon");

        driver.findElement(By.tagName("button")).click();

        String msg = driver.findElement(By.id("message")).getText();

        if (msg.equals("Registration Successful!"))
            System.out.println("Test Passed");
        else
            System.out.println("Test Failed");
    }
}
